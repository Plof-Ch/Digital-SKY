# Digital Sky — IMPLEMENTATION_PLAN

## Аудит текущего репозитория

| Область | Сейчас | Требуется по ТЗ | Риск |
|---|---|---|---|
| Стек | Статический HTML + CSS + vanilla JS, `localStorage` auth | Backend + БД + RBAC + ledger + PvP | Высокий: полный backend ещё не подключён |
| Публичный сайт | Есть (VTB-стиль, глобус, исследования) | Сохранить | Низкий |
| Auth | `admin/admin`, регистрация в localStorage | Роли, tenant, сессии | Средний |
| Кабинет | Упрощённый прототип (4 пункта меню) | 4 кабинета + разделы по макетам | Высокий UI-разрыв |
| Платежи / PvP | Нет | Полный lifecycle + симулятор | Высокий |
| Демометка | Частично | На всех финансовых экранах | Низкий |

## Стратегия

1. **Сейчас (UI P0):** пересобрать кабинет 1:1 с макетами (VTB glass / синий sidebar / все разделы) на демоданных с рабочей навигацией и формой перевода.
2. **Далее (Итерации 1–5 ТЗ):** Postgres + API + ledger + роли; UI не переписывать, а подключить к API.
